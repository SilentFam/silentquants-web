# silentquants.com

Static site. Served by GitHub Pages on silentquants.com with Cloudflare in front for TLS.

| Path | Contents |
|---|---|
| `/` | Start here — position, the odds, objections, the calculator |
| `/helix/` | The Helix app (prop firm and broker database) |
| `/helix/about/` | What Helix is, what it refuses to do |
| `/method/` | Read, write, test, then pay |
| `/log/` | Dated research record |
| `/resources/` | Library — what exists today, and what is only planned |
| `/tools/helix/` | Redirect to `/helix/` for old links |

Built from `build_sq_site.py` and `build_site3.py` in the Iris workbench; see CHANGELOG.md for the readable history.
